## 6. Timeline & Milestones

### Phase 1: Setup (Weeks 1-2)
- [ ] Install tracking (GA4, pixels, UTM)
- [ ] Set up ad accounts and campaigns

- [ ] Set up email flows (welcome, abandoned cart)
- [ ] Identify and outreach first batch of influencers
- [ ] Publish first 2-3 blog posts
- [ ] Set up social media accounts and content calendar

### Phase 2: Test & Learn (Weeks 3-6)
- [ ] Launch paid campaigns with test budgets
- [ ] Test 3-5 creative angles per platform
- [ ] Publish content consistently (3-5 social posts/week, 2 blog posts/month)
- [ ] Activate first influencer collaborations
- [ ] Optimize based on initial data (pause losers, scale winners)
- [ ] Build email list (target: X new subscribers)
- [ ] Milestone: [e.g., "First 50 paid customers", "Identify 2 winning creatives"]

### Phase 3: Scale (Months 2-4)
- [ ] Scale winning ad campaigns (20% budget increase every 3 days)
- [ ] Expand influencer program (10+ creators/month)
- [ ] Increase content output (5-7 social posts/week, 4 blog posts/month)
- [ ] Launch retargeting campaigns
- [ ] Optimize funnel based on data (fix biggest leak)
- [ ] Milestone: [e.g., "100 new customers/month", "CAC below $X"]

### Phase 4: Optimize & Grow (Months 5-6)
- [ ] Full funnel optimization (all stages)
- [ ] Expand to new channels (if budget allows)
- [ ] Launch loyalty/referral program
- [ ] Advanced audience segmentation (lookalikes, RFM)
- [ ] Milestone: [e.g., "200 new customers/month", "3x ROAS across paid", "20% repeat purchase rate"]
